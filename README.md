📋 Техническое задание (ТЗ)

## 1. Общие требования

Цель проекта: Создание PWA-приложения и веб-сайта для учета уличных кошек с функционалом карты и рейтинговой системой пользователей.

### Целевая аудитория:

- Волонтеры по защите животных

- Жители города, заботящиеся о кошках

- Сотрудники приютов

## 2. Функциональные требования

### 2.1 Модуль пользователей

- Регистрация через email
- Профиль пользователя с аватаром
- Система рейтинга на основе добавленных котов
- История добавленных котов

### 2.2. Модуль котов

- Добавление кота с фото (мультизагрузка)
- Геолокация на карте
- Категории характеристик:
- Статус здоровья
- Стерилизация
- Редактирование информации
- Модерация контента

### 2.3. Карта и навигация

- Интерактивная карта с кластерами
- Поиск по местоположению
- Фильтрация по характеристикам
- Переключение вид карта/список

### 2.4. PWA функционал

- Оффлайн-работа с кэшированием
- Push-уведомления
- Установка на устройство

## 3. Технические требования

### 3.1. Фронтенд

#### Технологии:

- Vue.js + TypeScript + Quasar (PWA Quasar)
- Карты: Leaflet

### 3.2. Бэкенд

#### Архитектура:

- Node.js (FastAPI/Django)
- База данных: SupaBase (PostGress)
- API: RESTful + WebSocket для уведомлений

## 4. Структура базы данных

```sql
-- Пользователи
Users (id, email, username, avatar, rating, created_at)

-- Коты
Cats (id, name, description, location(geography),
health_status, is_sterilized, created_by, created_at)

-- Фотографии
Photos (id, cat_id, url, is_main, uploaded_at)

-- Рейтинги пользователей
UserRatings (user_id, cats_count, level, updated_at)
```

## 5. Система рейтингов

```javascript
const ratingLevels = {
  1: { name: 'Котенок', minCats: 1, maxCats: 5 },
  2: { name: 'Друг кошек', minCats: 6, maxCats: 20 },

  4: { name: 'Кото-легенда', minCats: 51, maxCats: null },

```

## 6. Этапы разработки

#### Этап 1 (MVP - 4 недели)

- Базовая регистрация
- Добавление котов на карту
- Просмотр списка

#### Этап 2 (4 недели)

- Система рейтингов
- PWA функционал
- Модерация контента

#### Этап 3 (2 недели)

- Уведомления
- Социальные функции
- Оптимизация

## 7. Критерии приемки

- Приложение работает offline 24+ час
- Время загрузки < 3 секун
- Поддержка мобильных устройст
- Нет критических баго
- Прошло тестирование 10+ пользователями
